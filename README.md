# Macraoke

Karaoke with Emmanuel Macron's speeches. Live at https://ultragaucheforce.github.io/macraoke/ (a GitHub Pages project site, built with Vite `base: '/macraoke/'`)

Built with Vite, React, TypeScript and Tailwind. Deployed to GitHub Pages by `.github/workflows/main.yml` on every push to `main`.

```bash
npm ci
npm run dev      # local dev server
npm run build    # production build in dist/
```
